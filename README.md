# jins-kitchen

Jin's Kitchen: the recipe system of record's front end (`site/`, a single-file PWA at https://jins-kitchen.netlify.app), Supabase migrations, Notion-to-Supabase migration artefacts and the governance data protocol.

Netlify auto-deploys `site/` from `main`. Push = publish. Source of truth for edits is `Cooking/jins-kitchen` in the Playground folder; Cowork syncs it here and pushes.
